Tuleshwar Sahu — Resume / Portfolio Website
Files
index.html — page content and resume sections
style.css — dark professional theme, responsive layout, animations
script.js — mobile navigation, reveal-on-scroll effect, automatic year
Run locally
Open index.html in a browser. No build tools are required.
Publish with GitHub Pages
Upload all three files to the root of your GitHub repository.
Open repository Settings → Pages.
Under Build and deployment, select Deploy from a branch.
Select your main branch and / (root), then Save.
Wait a minute or two and open your GitHub Pages address.
Customize
Edit text and sections in index.html.
Change colors, spacing, fonts and layout in style.css.
Change mobile navigation and animation behavior in script.js.
The site intentionally does not include phone number, date of birth, or home address.
